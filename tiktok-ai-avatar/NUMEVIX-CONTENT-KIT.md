# Numevix — Short-Form Video Content Kit

10 vertical (1080×1920 · 30fps) Remotion compositions for TikTok / Reels / Shorts.
All in the exact Numevix palette (cream + antique gold + deep green light-luxury,
plus an on-brand deep-pine-ink dark-luxury surface for scroll-stopping hooks).
No voiceover — music + kinetic type + motion carry the message.

**Studio:** `cd tiktok-ai-avatar && npx remotion studio` → open the **Numevix-Promos** folder.
**Render one:** `npx remotion render 07-ProductDemo out/07.mp4`
**Render all:** loop the IDs `01…10` (see bottom).

## A/B testing plan
1. **Hook line** — test hook #1 vs #2 for each (same video). Winner = 3-sec view-through rate.
2. **Surface** — ink vs cream opening (01/03/05 are ink; try a cream re-cut). Dark hooks usually win the first second.
3. **CTA framing** — "free chart" vs "find your number" vs "comment your birthday" (engagement vs click).
4. **Length** — 18s vs 26s cut of 07 (trim the input scene). Watch completion rate.
5. **Cover text** — question ("Is your name blocking you?") vs statement. 
6. **First frame** — number-first (03/09) vs words-first (01/02). 
Run one variable at a time; 3–5k impressions per arm before calling it.
