# MG Kutz — Barbershop Website

A Dark Luxury-themed website for [MG Kutz](https://www.instagram.com/mgcuts1/) — Windsor's premier barbershop.

## Pages

| File | Description |
|---|---|
| `index.html` | Homepage — hero, about, services, barbers, Instagram, contact |
| `barbers.html` | Barber profiles with portfolios |
| `book.html` | 4-step appointment booking wizard |
| `contact.html` | Map, hours, contact form |
| `admin.html` | Barber portal (hidden — not linked publicly) |

## Setup

See [SETUP.md](SETUP.md) for instructions on:
- Creating a Supabase project and running the database schema
- Setting up Google Calendar API credentials
- Adding barber accounts
- Deploying to GitHub Pages

## Tech Stack

- **Frontend**: Vanilla HTML, CSS, JavaScript (no build step)
- **Database**: [Supabase](https://supabase.com) (free tier)
- **Auth**: Supabase Auth (email/password)
- **Storage**: Supabase Storage (portfolio photos)
- **Calendar**: Google Calendar API + OAuth 2.0
- **Hosting**: GitHub Pages (free)
